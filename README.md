# Assassin

The sniper must figure out who the assassins are in the crowd of NPCs. Stop them with 3 bullets before they assassinate all the others!

## Getting Started

First, run the development server:

```bash
npm run dev
```

## Multiplayer

Aiming to have multiplayer via P2P and Websockets. Websocket backend code is not in this repo or available at this time. P2P code will be included here.
